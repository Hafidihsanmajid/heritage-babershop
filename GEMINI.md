# Konteks Proyek
- Framework: Laravel 12 (PHP 8.2+)
- Styling: Tailwind CSS
- Frontend Template: Laravel Blade (.blade.php)

# Aturan Agen
1. Pastikan setiap membuat form input di Blade, name attribute identik dengan validasi di Controller.
2. Gunakan utility classes Tailwind yang clean dan responsif.
3. Selalu tambahkan route baru di `routes/web.php`.
